## **Usage**

Python
You are recommended to open the python files first.

The assignment has requested to work on data visualization in python first.

First, we import the required packages and libraries for the work.

Second step is to perform data exploration and preparation.
This involves cleaning data from missing values, duplicates and irrelevant variables.

Third step is working on data visualization requirements.

First problem is showing the most watched genres.
Second problem to show ratings distribution
The visualization is using bar chart with different styles.
Third problem is to conduct statistical analysis by showing the histogram in bellcurve form.

You can run the code at each step to see the progression of the answer to assignment.
Upon completion of python code review, you can open the R file.

R
First, we import the required packages and libraries for the work.

Second step is to perform data exploration and preparation.
This involves cleaning data from missing values, duplicates and irrelevant variables.

Third step is working on data visualization requirements. 
The assignment is requesting at least 1 visualization technique to be shown in R programming.
We provide 2 examples.

First example is showing the most watched genres in bar chart.
Second example to show ratings distribution per country in a pie chart.

You can run the code at each step to see the progression of the answer to assignment.
